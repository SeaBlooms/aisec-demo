# Renewal Playbook

For accounts with flat or declining usage 120 days before renewal:

1. Run an adoption deep-dive: active seats by team and region.
2. Agree a written enablement plan with the executive sponsor, with a 60-day activation target.
3. Bring a right-sizing option proactively rather than waiting for procurement to ask.
4. Escalate to the CS director if health score stays below 70 for two consecutive months.
